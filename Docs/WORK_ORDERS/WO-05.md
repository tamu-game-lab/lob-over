# WO-05 — Voice line batch with Kokoro

## Goal

`python Tools/voice/make_voice.py Data/Scenarios/stage1_texas.json` writes one 24 kHz mono WAV per entry in the scenario's `lines[]` to `Voice/stage1_texas/<lineId>.wav`, with a distinct voice per `speaker`, and skips lines whose text has not changed since the last run (a `manifest.json` with text hashes). The host (WO-03) serves `Voice/` and the pages play these files when present. Placeholders only; recorded lines replace them later by dropping files with the same names.

## Read

- `AGENTS.md`
- `Data/Scenarios/stage1_texas.json` and `stage2_texas.json` (`lines[]`)
- Kokoro's README in the installed package (`python -c "import kokoro, os; print(os.path.dirname(kokoro.__file__))"`) for the pipeline API; the orchestrator has run `pip install kokoro soundfile` and, on Windows, installed espeak-ng (fallback phonemizer)

## You may change

- `Tools/voice/**`, `Voice/**`

## Build

1. `Tools/voice/make_voice.py`: arguments scenario path, `--out Voice/`, `--force`. Loads the scenario, maps `speaker` → Kokoro voice id via `Tools/voice/voices.json` (ship a default: `pm` an older American male, `radio` a neutral American female, `foreman_exc`/`foreman_pipe`/`foreman_back` three distinct male voices; pick from the voices Kokoro lists; lang `a` for American English), speed 1.0 for the PM, 1.1 for the radio.
2. Generates with the `KPipeline` API, concatenates the segments, writes 24 kHz WAV via `soundfile`. Trims leading/trailing silence to 150 ms. Normalizes peak to -3 dBFS.
3. `Voice/<stage>/manifest.json`: `{lineId: {text, sha1, voice, seconds}}`; unchanged text is skipped unless `--force`; removed lines leave their files (noted in output).
4. Radio lines get a light "radio" treatment: band-pass 300–3,400 Hz and a short squelch click at start and end (pure numpy; no extra dependency). Foremen get none. Keep it subtle.
5. Prints one row per line: `<lineId>  <speaker>  <generated|skipped|failed>  <seconds>  <file>`, no summary line, so `grep -c skipped` counts rows. Exits non-zero if any line failed.
6. `Tools/voice/README.md`: 10 lines on how to regenerate after a text change, how to swap a voice, and how recorded files replace placeholders (same file name, 24 kHz mono WAV).

## Acceptance checks

```
python Tools/voice/make_voice.py Data/Scenarios/stage1_texas.json ; echo exit=$?            # exit=0; 12 files
python Tools/voice/make_voice.py Data/Scenarios/stage2_texas.json ; echo exit=$?            # exit=0; 11 files (shared ids regenerate per stage folder)
ls Voice/stage1_texas/*.wav | wc -l                                                           # 12
python -c "import soundfile as sf,glob; [print(f, sf.info(f).samplerate, round(sf.info(f).duration,1)) for f in sorted(glob.glob('Voice/stage1_texas/*.wav'))]"   # 24000 each, 1.5-15 s each
python Tools/voice/make_voice.py Data/Scenarios/stage1_texas.json | grep -ci skipped          # 12 on the second run
git status --short                                                                            # Tools/voice, Voice/
```

The orchestrator listens to nothing; it checks durations and that `pm_open_01.wav` is the longest Stage 1 line.
