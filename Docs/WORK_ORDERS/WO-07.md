# WO-07 — Quest client core: WebSocket, protocol, site-state model, dispatcher, HUD

## Goal

A Unity assembly `LOBOver.Client` (`Assets/LOBOver/Runtime/Client/`, asmdef, references only UnityEngine, Newtonsoft.Json and `System.Net.WebSockets`) that connects to the Node host as the Site seat, keeps a typed copy of the Site view from every `state`, raises C# events for `event`, `voice`, `inspection`, `report`, `result`, `ack`/`nack`, and sends every Site action from `Docs/PROTOCOL.md`. A debug scene `Assets/LOBOver/Scenes/ClientDebug.unity` with a text HUD proves it in the Editor against the Node host with no XR. Nothing visual beyond the HUD.

## Read

- `AGENTS.md`, `Docs/ORCHESTRATOR_PHASE1.md` (the Unity rules; you never run Unity, the orchestrator does)
- `Docs/PROTOCOL.md` (whole), `Docs/VR_SLICE.md` section B
- `Monitor/src/sim/views.js` (the exact Site view fields) and `Monitor/src/host/clients.js` (hello/welcome/mirror handling)

## You may change

- `Assets/LOBOver/Runtime/Client/**`, `Assets/LOBOver/Tests/**`, `Assets/LOBOver/Scenes/ClientDebug.unity` (created by your editor script, see 6), `Assets/LOBOver/Editor/ClientDebugSceneBuilder.cs`
- `Packages/manifest.json`: only to add `com.unity.nuget.newtonsoft-json` if the orchestrator has not

## Build

1. `Protocol.cs`: DTOs for every message in `Docs/PROTOCOL.md` (`Hello`, `Welcome`, `State`, `Ack`, `Nack`, `EventMsg`, `Report`, `Inspection`, `Voice`, `Result`, `Cmd`, `Ctrl`), `[JsonProperty]` names matching the wire exactly, unknown fields ignored (`MissingMemberHandling.Ignore`). `SiteView.cs`: `Truck`, `Crew[]`, `TrenchCell[]`, `Board[]`, `Sky`, `Gate`, `ActiveEvent`, `Order[]`, mirroring `views.js` field for field (read it; do not guess).
2. `HostConnection.cs`: `ClientWebSocket`, connect to `ws://<host>:<port>/ws`, a background receive loop into a `ConcurrentQueue<string>`, `Pump()` called from a MonoBehaviour `Update` to parse and dispatch on the main thread, send with a lock, reconnect with backoff 1 s to 10 s, `Status` enum, a `MaxFrame` of 1 MB.
3. `SiteClient.cs` (MonoBehaviour): `Connect(host, port)`, sends `hello {seat:"site", client:"quest", name}`, exposes `View` (latest), `Stage`, `DisplayDay`, `Speed`, events `OnState`, `OnEvent`, `OnVoice`, `OnInspection`, `OnReport`, `OnResult`, `OnAck`, `OnNack`, `OnConnection`; methods `MoveTo(int ft)`, `Mount()`, `Dismount()`, `Inspect(string target)`, `Flag(int ft, string note)`, `StopWork(int zone)`, `Confirm(string orderId, bool done)`, `Listen()`, each with a generated `id` (`q-<n>`) returned to the caller; ids are matched to acks.
4. `HostAddress.cs`: PlayerPrefs-backed host and port with defaults `192.168.0.2:7331`; `HostAddressPanel.cs`: a uGUI panel with an input field and a Connect button (works with mouse in the Editor; WO-09 wires it to the controllers).
5. `ClientHud.cs`: a uGUI text that prints connection status, stage, day, speed, truck station, the three crews' station and status, the last event title, the last inspection text, the last nack reason. Plain text, no colours that judge anything.
6. `ClientDebugSceneBuilder.cs` (Editor, menu `LOB Over/Build/Client Debug Scene`): creates `ClientDebug.unity` with a camera, an EventSystem, the panel, the HUD, a `SiteClient`, and keyboard shortcuts in a `DebugKeys.cs` (M = moveTo the station typed in a field, D = dismount, I = inspect wall, F = flag, S = stop work, C = confirm first landed order done).
7. Tests, `Assets/LOBOver/Tests/` (asmdef with `UNITY_INCLUDE_TESTS`): EditMode `ProtocolTests` (every DTO round-trips a sample JSON taken verbatim from `Docs/PROTOCOL.md`; unknown fields do not throw); PlayMode `SiteClientPlayModeTests` that starts `node Monitor/src/host/server.js Data/Scenarios/slice_texas.json --port 7332` with `System.Diagnostics.Process` (repo root resolved from `Application.dataPath`), connects, awaits `welcome` with seat `site`, sends `MoveTo(520)`, asserts an `ack` and then a `state` with `truck.stationFt == 520` within 5 s, sends `ctrl start` is not possible from the Site seat so the test asserts `speed == "paused"`, then kills the host in teardown.
