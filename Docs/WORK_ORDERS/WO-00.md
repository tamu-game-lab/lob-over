# WO-00 — Scaffold `Monitor/`: package, scripts, seeded RNG, test runner

## Goal

`Monitor/` becomes a runnable Node 20 project with the folder layout every later work order expects, a seeded deterministic RNG, a shared constants module that reads `Data/catalog.json`, and a passing `npm test`. Nothing game-specific yet beyond constants.

## Read

- `AGENTS.md`
- `Docs/PROTOCOL.md` (Transport section only, for the port and paths)
- `Data/catalog.json`

## You may change

- `Monitor/package.json` (dependencies are already installed by the orchestrator: `ws`, `playwright`; do not add others)
- `Monitor/src/**`, `Monitor/test/**`, `Monitor/README.md`
- `Monitor/.gitignore` (node_modules, test-results, out)

## Build

1. `Monitor/package.json`: `"type": "module"`, scripts:
   - `"test": "node --test"` (Node's default discovery: name every test file `*.test.js`; passing a directory path is not supported on current Node)
   - `"validate": "node src/scenario/validate.js"` (WO-01 fills it; create the file as a stub that prints usage and exits 2)
   - `"headless": "node src/sim/headless.js"` (WO-02 fills it; stub as above)
   - `"host": "node src/host/server.js"` (WO-03 fills it; stub as above)
   - `"e2e": "node --test e2e/stage1.e2e.js"` (WO-03)
2. Folders: `src/common/`, `src/scenario/`, `src/sim/`, `src/host/`, `web/`, `test/`, `e2e/`, `out/` (gitignored).
3. `src/common/rng.js`: a seeded PRNG (mulberry32 or xoshiro128**), `makeRng(seed)` returning `{ next(): float in [0,1), int(lo, hi), pick(array), state() }`; `state()` returns a serializable state so a run can be resumed or compared. Document the algorithm in a comment.
4. `src/common/catalog.js`: `loadCatalog(path = '<repo>/Data/catalog.json')` that resolves the repo root from the module's location, returns the parsed catalog, and exposes `machine(key)`, `protection(key)`, `city(key)` with a clear error for unknown keys.
5. `src/common/units.js`: `fmtStation(ft)` (`720 -> "7+20"`, `1500 -> "15+00"`), `parseStation("7+20") -> 720`, `displayDay(t)` (`Math.floor(t) + 1`), `fmtUsd(n)` (`"$278,400"`).
6. `src/common/log.js`: a tiny logger with levels that writes to stderr, used by every later module (no console.log in library code).
7. Tests in `test/`: `rng.test.js` (same seed → same first 100 values; different seeds differ; `state()` round-trips), `catalog.test.js` (8 machines, `excavator_standard.rateFtPerDay === 220`, `cities.texas.remobilizationDelayDays === 1`, unknown key throws), `units.test.js` (the examples above).
8. `Monitor/README.md`: 15 lines: what lives where, the five npm scripts, how to run the host (the command, the three URLs).

## Acceptance checks (the orchestrator runs these from the repo root)

```
npm --prefix Monitor test                    # all tests pass, at least 3 test files
node -e "import('./Monitor/src/common/rng.js').then(m=>{const a=m.makeRng(1),b=m.makeRng(1);console.log(a.next()===b.next())})"   # true
node -e "import('./Monitor/src/common/units.js').then(m=>console.log(m.fmtStation(720), m.parseStation('15+00'), m.fmtUsd(278400)))"   # 7+20 1500 $278,400
git status --short                           # only files under Monitor/
```
