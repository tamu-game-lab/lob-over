# WO-10 — Quest build: APK, host-address panel on the controllers, 72 Hz, install

## Goal

`LOB Over/Build/Quest APK` (an editor menu item the orchestrator runs through the Unity MCP with the Editor open) produces `Builds/LOBOver-<date>.apk` for the Quest 3S: Android, ARM64, IL2CPP, OpenXR with the Meta Quest feature group, the `Site` scene first, 72 Hz, the host-address panel usable with the controllers. `adb install -r` puts it on the headset; the first launch asks for the PC's address once and remembers it.

## You may change

- `Assets/LOBOver/Editor/QuestBuild.cs`, `Assets/LOBOver/Runtime/VR/HostAddressVR.cs`, `Assets/LOBOver/Prefabs/VR/**`, `ProjectSettings/EditorBuildSettings.asset` (scene list), `Builds/` (gitignored output)

## Build

1. `QuestBuild.cs`: sets the scene list (`Site.unity` first, `ClientDebug.unity` excluded), checks the Android settings the Project Setup Tool expects (min SDK 32, ARM64, IL2CPP, OpenXR loader with the Meta Quest Support feature enabled and the Quest 3S target) and fails with one clear message per missing item rather than changing project settings silently; then `BuildPipeline.BuildPlayer` to `Builds/LOBOver-<yyyyMMdd-HHmm>.apk`, development build off, a `-buildOnly` flag.
2. `HostAddressVR`: the WO-07 panel rebuilt as a dashboard page: a numeric keypad of physical buttons for the address (digits, dot, backspace, Connect), the last address pre-filled from PlayerPrefs, the result line "connected" or the error text. Keyboard input stays for the Editor.
3. Frame rate: `OVRManager.display.displayFrequency = 72` at start; fixed foveated rendering level 2; the URP mobile asset the project already has (`Assets/Settings/Mobile_RPAsset.asset`).
4. A `BuildInfo` text on the dashboard: build date and git short hash (written by `QuestBuild.cs` into a `Resources/buildinfo.txt`).

## Acceptance checks

```
# Unity (MCP, Editor open): execute LOB Over/Build/Quest APK -> Builds/LOBOver-*.apk exists, build log has no errors
adb install -r Builds/LOBOver-*.apk                      # Success
adb shell am start -n com.tamu.gamelab.lobover/com.unity3d.player.UnityPlayerGameActivity   # (or the package name ProjectSettings has) app starts
adb logcat -d | grep -E "LOBOver|welcome" | tail -5     # shows the welcome message for seat site after Bryan connects
git status --short     # only Assets/LOBOver/**, ProjectSettings/EditorBuildSettings.asset
```
